# Assignment 5 — Profile Card UI/UX Design 💻

A simple and modern **Profile Card UI/UX Design** created using **HTML and CSS**. This project demonstrates the use of CSS Flexbox, styling, shadows, borders, hover effects, and Font Awesome icons to create a professional-looking profile card.

## 📌 Project Overview

This project is part of a **Web Development Assignment** and focuses on creating a visually appealing profile card interface.

The design contains:

* A large **Profile Card UI/UX Design** heading
* Profile image
* Developer designation
* College information
* Social media icons
* Subscribe and Message buttons
* Like, comment, and share statistics
* Hover effects
* Responsive flexbox-based layout

## 🚀 How to Run

1. Download or clone the project.

2. Make sure `index.html` and `img.png` are in the same folder.

3. Open `index.html` in any modern web browser.

4. The Profile Card UI will be displayed.

## 🌐 External Dependency

This project uses **Font Awesome** through a CDN:

```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.1/css/all.min.css">
```

An internet connection may be required for the Font Awesome icons to load.
